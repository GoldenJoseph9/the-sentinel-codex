# Phase Two — Investigation refinement (V6)

## Implemented
- Expanded manual comparison from one indexed pair to 18 record pairs (17 evidence-graph pairs plus CASE 0017 / ITERATION 017).
- Comparison remains optional; it does not block story progress or alter canon.
- Qualified automatic correlation language to avoid presenting interpretations or motives as proven facts.
- Renamed the Codex heading from Deductions to Record Correlations.
- System-only records no longer appear as ordinary evidence cards.
- Evidence cards without image files no longer render empty image tags.
- Existing Observer route and saved progress are preserved; no save-key migration.

## Limitations
- Indexed comparison covers selected meaningful pairs, not every possible combination of recovered records.
- No browser-based end-to-end verification has been performed.
- Existing decision logic, chapter content, artwork manifest and save schema remain unchanged.
